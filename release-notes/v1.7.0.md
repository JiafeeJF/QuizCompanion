# 物联宝典 v1.7.0

## 版本更新说明

1. 模拟考试新增试卷打印式打开动画，点击试卷后可直观看到试卷从打印机中逐步展开。
2. 考试详情改为在模考页面内无缝呈现，减少页面跳转感，试卷信息、开始答题和上次成绩入口保持完整。
3. 优化班级排名加载与入场效果，真实排名提前加载并平滑显示，避免内容突然出现。
4. 修复试卷纸张加载、放大和关闭过程中的闪烁、叠影与位置跳变。
5. 优化不同手机屏幕下的动画尺寸和性能，支持系统“减少动态效果”设置。
6. 详情、开始作答、查看成绩和交卷结果持续全屏衔接，仅返回试卷列表时恢复底部导航。

## 新版本公告

### 物联宝典 v1.7.0 已发布

本次更新重点升级了模拟考试体验。点击试卷后，将以简洁的打印动画展示试卷，并在当前模考页面中自然展开考试详情和班级排名，浏览过程更加连贯。

同时修复了部分设备上纸张动画闪烁、放大突兀和关闭时跳动的问题，并优化了手机端适配与动画性能。考试计时、答题、交卷、成绩和排名规则保持不变。

建议 Android 用户升级至 v1.7.0 体验新版模考交互。
