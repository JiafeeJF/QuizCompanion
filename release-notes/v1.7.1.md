# 物联宝典 v1.7.1

版本号：1.7.1；Android versionCode：36。

## 更新内容

1. 统一模考列表、考试通知和直达链接的打开方式，均使用新版打印详情流程。
2. 考试详情、开始作答、查看成绩、再考与交卷结果持续全屏衔接，仅退出至试卷列表时恢复底部导航。
3. 重新同步并构建 Android 安装包，应用内版本号与安装包统一更新为 1.7.1。

## 更新公告

物联宝典 v1.7.1 已发布

本次更新统一了模拟考试的打开体验。从试卷列表、考试通知或直达链接进入，均可使用新版打印详情界面。开始答题、查看成绩和交卷后的结果页面保持全屏衔接，返回试卷列表后恢复底部导航。

建议安卓用户安装 v1.7.1，安装后可在「我的」中确认当前版本。
